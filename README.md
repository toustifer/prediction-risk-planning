# 动态障碍物运动预测与时空风险规划

无人载具系统课程项目。成员为程嘉俊、孟瀚珅。暂定验收日期为2026年12月8日。

研究题目为《基于动态障碍物运动预测与时空风险地图的无人车局部规划研究》。采用已知目标ID、位置序列和自车位姿，研究运动预测、不确定性建模与局部规划。
