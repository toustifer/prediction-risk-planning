# 无人系统实验方案与开发交接 v1

制定于2026年11月14日。程嘉俊负责方法审定与技术验收，孟瀚珅负责实现和实验。12月5日预验收，12月8日暂定最终验收。

本文给出首轮开发默认值，所有数值属于拟定参数。先运行预实验检查冲突是否形成、能否制动以及计算耗时，再冻结正式版本。本文细化《实现任务书》，涉及规划候选、时间步长和实验配置时以本文为准。

## 1 研究问题与交付目标

研究已知目标ID、带噪位置观测条件下，运动预测和位置不确定性建模如何影响无人车通行安全与效率。

首轮系统使用二维平面、固定自车行驶中心线和纵向速度规划。自车输出加速、保持、减速和停车动作。地图展示二维风险分布，规划评价沿中心线的时空轨迹。研究结论限定在该动作空间内。

必须交付可重复仿真、三组规划对照、逐帧日志、汇总结果和演示视频。运动预测误差单独在离线回放中评价，闭环效果在仿真中评价。

## 2 统一仿真条件

| 参数 | 首轮默认值 |
| --- | --- |
| 全局坐标 | x沿道路，y横向，米和秒 |
| 道路范围 | x在[-5,70]，y在[-4,4] |
| 自车 | 初始位置(0,0)，航向0，初速5 m/s |
| 自车几何 | 圆，半径1 m |
| 目标半径 | 行人0.35 m，骑行者0.6 m，汽车1 m |
| 自车目标 | x达到60 m，保持y=0 |
| 速度约束 | 0至5 m/s |
| 加速度约束 | -3至2 m/s² |
| 观测、滤波、规划、执行周期 | 统一0.1 s |
| 预测时域 | 3 s，共30个未来步 |
| 单次运行上限 | 40 s |
| 热图分辨率 | 0.25 m，显示自车前后局部区域 |

圆模型和尺度是简化仿真设定。目标独立按预设轨迹运动。自车位姿无噪声，目标位置观测带噪。真值仅供仿真生成和评价模块使用。

每轮执行顺序为读取当前观测、滤波更新、预测、生成候选控制、风险评价、选取动作、执行0.1秒、检查碰撞和终止条件。位置积分应处理速度触及0或上限的时刻，避免停止后反向运动。

## 3 三组方法与公平对照

所有方法使用同一个卡尔曼滤波器、圆形几何、候选轨迹、控制约束和代价权重。改变目标未来位置表示。

| 方法 | 未来目标表示 | 单目标风险 |
| --- | --- | --- |
| A 当前状态保持 | 后验位置保持不变 | 两圆重叠时1，否则0 |
| B 确定性预测 | 匀速预测均值 | 两圆重叠时1，否则0 |
| C 概率风险预测 | 匀速均值与协方差 | 预测中心落入碰撞区域的概率 |

B对A用于检验运动预测，C对B用于检验本方案中的概率表示。C与B的风险评分含义不同，报告时说明阈值敏感性和安全效率权衡。

同一工况和种子下，三组共享目标真值、目标观测和漏测时段。首轮采用固定覆盖范围内全部目标可观测的设定，避免自车动作改变观测输入。

## 4 场景定义

下表轨迹均从t=0开始。预热使用t=-1至0的轨迹观测，按相同函数向前延拓，自车在t=0开始执行。

| 编号 | 情境 | 名义目标轨迹 | 验证重点 |
| --- | --- | --- | --- |
| E0 | 空道路 | 无目标 | 正常前进、运行开销 |
| E1 | 行人横穿 | p(t)=(15,4.5-1.5t) | 相遇前预测、减速和恢复 |
| E2 | 同向骑行者 | p(t)=(12+2t,0) | 提前降低车速、稳定跟随 |
| E3 | 汽车切入 | x=10+3t；t<1时y=3.2；1至3秒y=3.2-1.6(t-1)；之后y=0 | 方向改变与模型失配 |
| E4 | 多目标 | E1行人与E2骑行者同时存在 | 多目标风险融合 |

E1速度变化实验令横向速度v取1.2、1.5、1.8 m/s，初始y统一设为3v，使名义横穿中心线时刻保持3秒。这些是受控仿真工况，目标速度不根据方法变化。

正式种子可对E1/E2的初始x加入均匀[-1,1] m扰动，对E3切入开始时刻加入均匀[-0.2,0.2] s扰动。生成后保存真值文件，检查冲突窗口是否仍存在。

## 5 噪声与漏测

位置观测z=p_true+ε，ε服从零均值二维高斯，R=σ²I。

| 条件 | 参数 |
| --- | --- |
| N0 | σ=0.05 m |
| N1 | σ=0.2 m |
| N2 | σ=0.5 m |
| N3 | σ=0.2 m，目标在[2.0,2.5)秒无观测 |

每个目标按ID维护滤波状态。漏测期间只预测，首轮场景中的目标生命周期持续到回合结束。仿真噪声种子与风险采样种子分开，改变采样规模不能改变输入观测。

## 6 预测模块

使用《实现任务书》的匀速卡尔曼模型和Joseph协方差更新。统一基础步长0.1秒，未来预测也逐步使用0.1秒递推，避免变更步长时改变随机加速度模型的含义。

建议初始位置协方差采用R，速度方差取4 (m/s)²，速度初值为0。预热期间持续更新。加速度标准差σa在开发集上比较0.5、1、2 m/s²，正式实验统一冻结，允许如实报告某些类别或转向场景失配。

输入包含timestamp、目标ID、z、R、radius、valid。输出包括future_timestamps[30]、means[30,2]、covariances[30,2,2]。数组时间为绝对时间。

## 7 风险地图

对候选自车中心q，在未来时刻τ计算p_i=P(||X_i(τ)-q||≤r_ego+r_i)。采用蒙特卡洛近似，初始N=512，开发阶段比较N=256、512、2048的精度和耗时。

同一目标同一未来步的标准正态样本由固定种子生成并复用于所有候选位置。采样种子由回合种子、规划步、目标ID、预测步组合生成，不能受循环顺序影响。

多目标采用R(q,τ)=min(1,Σp_i)，将其标为碰撞风险上界。热图表示自车中心放在该位置时的风险，包含双方尺寸。

规划直接评价候选轨迹位置，演示热图按需生成。热图查询和候选点查询共用同一个概率计算函数。超出预测时域的查询应返回输入错误。

## 8 候选规划与代价

第一阶段采用两个分段常加速度，每段1.5秒。每段加速度从{-3,-1.5,0,1,2} m/s²选择，共25组候选，按0.1秒展开。速度上限和下限触及时使用饱和动力学。检查整条圆形车身是否越出道路边界。

对于每条轨迹，定义归一化风险均值C_r=(1/K)ΣR(q_k,τ_k)，进度损失C_p=clip(1-(x_K-x_0)/(v_max T),0,1)，控制变化C_u为各步(a_k-a_(k-1))²/25的均值，首步以前一周期已执行加速度作参照。

首轮J=10 C_r+C_p+0.1 C_u。开发阶段比较风险权重{3,10,30}，三组共享正式选定值。

候选要求max_k R≤ε，开发阶段统一比较ε={0.05,0.1,0.2}，默认0.1。A/B风险取0或1。若没有候选通过阈值，采用最大允许减速度并记录fallback，随后继续仿真。该动作仍需参与碰撞统计。

代价相同时按更小风险、更小控制变化、固定候选序号决定。每次只执行第一步控制，然后重新规划。

## 9 碰撞与终止

真值碰撞用双方圆形几何检查。对相邻仿真状态的相对线性运动计算最小距离，若使用非线性步内积分则增加检查子步并核验误差。执行阶段碰撞判据在三组中保持一致。

发生碰撞或越界立即终止并标记失败。到达x≥60且此前无碰撞越界记为成功。40秒未完成记为超时。最小净间距为中心距离减双方半径之和，碰撞可为负值。

## 10 实验批次

1. 工程验收，E0与E1，单个固定种子，检查输出和控制行为。
2. 预实验，种子0至9，检查场景、参数和运行耗时，冻结最终配置。
3. 主实验，E1至E4 × N0至N3 × 30个正式种子100至129 × 3种方法，共1440回合。
4. 空道路检查，E0每种方法运行一次并保存完整日志。
5. 扩展消融，优先比较预测时域1、2、3秒，以及风险权重或阈值敏感性。主实验完成后按时间选择。

若1440回合计算预算不足，可在正式运行前将每组种子统一降为10个并记录理由。禁止根据测试结果挑选有利种子。算法调参后需标记新版本并重跑受影响的整组对照。

## 11 指标与统计

| 指标 | 定义 |
| --- | --- |
| 碰撞率、越界率、超时率 | 对全部回合分别计数并报告分母 |
| 完成率 | 成功回合数/全部回合数 |
| 到达时间 | 仅对成功回合统计，同时报告完成率 |
| 停车时间 | v<0.1 m/s的执行时间累计 |
| 最小净间距 | 每回合真实几何最小净间距 |
| 控制平顺性 | 记录加速度变化和每步jerk=(a_t-a_prev)/dt |
| 计算耗时 | 规划周期均值、p95和最大值，注明硬件与是否包含绘图 |
| 预测质量 | 在固定长度离线真值回放上计算ADE/FDE及95%位置置信椭圆覆盖率 |

离线预测评价仅使用未来真值完整的窗口，统计窗口数和预测时域。95%二维高斯置信区域采用马氏距离平方≤5.991，记录总体与各预测时距覆盖率。

三种方法按相同种子配对展示，报告分布和失败数量。时间对比同时提供三组共同成功回合的配对结果。若给出置信区间，以回合为重采样单位，避免把相关帧当成独立样本。

## 12 输出文件与开发入口约定

每轮输出到runs/<实验批次>/<场景>/<条件>/<方法>/<种子>/。

- config.json保存全部参数、代码提交号、依赖与硬件。
- observations.csv保存时间、目标ID、观测位置、valid和噪声条件。
- trajectory.csv保存时间、自车位置速度、控制、所选候选、风险与fallback。
- predictions.npz保存目标ID、预测时间、均值、协方差及数组索引说明。
- metrics.json保存单回合结果、各失败标记和耗时。
- summary.csv按回合汇总，绘图脚本直接读取该表。
- 典型工况输出mp4，包含道路、自车、目标、预测均值、风险切片及当前动作。画面标明仿真参数。

建议提供simulate、evaluate、render三个命令入口，具体命令由实现者在README登记。单场景调试与批量实验共用运行函数。

## 13 模块验收与交接顺序

| 顺序 | 验收内容 | 通过标准 |
| --- | --- | --- |
| 1 | 仿真与时钟 | 同种子重跑一致，速度有界，停车后无倒退 |
| 2 | 预测 | 人工匀速样例正确，漏测可运行，协方差有效 |
| 3 | 风险 | 概率有界，远离/重叠样例正确，圆心各向同性解析样例与采样误差相符 |
| 4 | 规划 | 无障碍保持前进，横穿有动作响应，fallback与超时可追踪 |
| 5 | 对照 | 三组共享观测、约束与种子，日志可定位每次失败 |
| 6 | 交付 | 干净启动能复现一个回合和汇总图，附成功与失败录像 |
