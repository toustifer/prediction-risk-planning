# 当前研究方案与计划

更新日期为2026年11月14日。

## 输入与场景
二维仿真提供地图、自车位姿、目标ID、位置序列与尺寸，给位置添加可控噪声。采用行人横穿、骑行者慢行、车辆切入工况。

## 方法
1. 卡尔曼滤波采用匀速状态模型，状态为位置与速度，保存协方差、时间戳和观测有效标记。
2. 预测未来各时刻的位置分布。初始拟设预测时域3秒、间隔0.2秒，预实验后冻结参数。
3. 根据双方尺寸定义碰撞区域，对目标位置分布积分得到单目标碰撞概率。首版可采用外接圆近似。
4. 同一时刻的多目标风险使用min(1,各目标碰撞概率之和)作为保守上界。跨时间累计用于轨迹代价。
5. 生成满足道路与车辆运动约束的候选轨迹，综合风险、进度和控制变化评价，执行首段并循环更新。

## 对照与评价
比较当前位置保持不变、确定性匀速预测、概率风险规划三种方法。共享车辆模型、场景、候选轨迹和随机种子。

记录预测误差、置信区域覆盖率、碰撞率、最小间距、越界次数、完成率、到达时间、停车时间、单周期耗时与控制变化。报告成功和失败案例，评价噪声、漏测与转向的影响。
