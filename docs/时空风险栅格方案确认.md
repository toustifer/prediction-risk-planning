# 时空碰撞风险栅格方案确认记录

确认日期为2026年11月14日。

## 已确认的研究流程

动态目标跟踪与预测生成各目标的未来位置分布，结合自车与目标尺寸形成概率软掩码，融合为时空碰撞风险栅格。规划器按照候选轨迹的到达时间查询风险，在道路和车辆运动约束下选择低风险轨迹。

首轮输入继续采用已知目标ID与带噪位置序列。跟踪模块负责连续状态估计与未来预测，关联接口可在后续真实检测接入时扩展。

## 软掩码定义

M_i(x,y,t)表示在未来绝对时间t，自车中心位于(x,y)时与目标i发生碰撞的概率。根据目标中心预测分布和双方几何轮廓定义碰撞区域，再计算该区域的概率质量。

首轮沿用圆形几何近似，目标与自车半径共同决定碰撞区域。位置概率密度需要经过碰撞区域积分才能得到这里的概率值。

多目标采用R(x,y,t)=min(1,Σ_i M_i(x,y,t))，作为多目标碰撞概率上界。静态障碍与道路边界保留为独立可通行约束。

## 栅格与接口

每个时间层保存绝对时间戳、地图原点、分辨率、行列方向和二维风险数组。预测模块提供目标ID、未来时间戳、位置均值、协方差和几何尺寸。首轮沿用0.1秒步长、3秒预测时域，具体参数按预实验冻结。

维护每个目标的软掩码贡献，再融合得到全局风险层。规划查询输入候选自车中心与绝对到达时间，返回风险上界及有效标记。地图范围外或预测时间范围外的查询返回无效，交由规划器处理。

规划轨迹按对应时间层评价风险，沿轨迹累计风险作为代价。热图展示可选择时间切片，最大值投影用于整体观察。开发时明确栅格取值和时空插值规则，并用直接概率查询检查栅格近似误差。

## 地图维护规则

| 触发条件 | 操作 |
| --- | --- |
| 新观测到达 | 更新目标状态，替换该目标的未来软掩码 |
| 短时漏测 | 继续运动预测与协方差传播，更新未来掩码 |
| 重新观测 | 用更新后的后验状态替换旧贡献 |
| 时间推进 | 删除过期时间层，补充新的远期层 |
| 目标生命周期结束 | 移除对应贡献并重新融合，记录移除原因 |

按目标ID维护贡献，避免累积旧掩码形成残留。各目标必须对齐到相同绝对时间再融合。删除规则需考虑遮挡与漏测，首轮仿真沿用回合内目标持续存在的生命周期设定。

## 规划与验收

规划满足道路边界、车身几何、速度和加速度限制，并检查制动可行性。沿用首轮纵向速度规划，允许减速、等待和恢复前进。后续增加横向避让时，补充车辆转向和曲率约束。

新增验收项目包括同一位置在不同未来时间的风险差异、目标更新后旧贡献消失、多目标移除后的正确重融合、漏测时预测更新，以及查询越界处理。

首轮开发交付单目标多时刻软掩码、融合风险栅格、轨迹按时间查询的结果和动态演示。开发可先完成概率查询函数，再构建栅格缓存，两者采用相同的风险定义。
